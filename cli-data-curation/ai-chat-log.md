# AI Chat Log – Cultural Media Collection

## AI Tool Used
ChatGPT (OpenAI)

## Purpose
I used ChatGPT to help me build and test a Python command-line application and an HTML interface for collecting cultural media data.

## Summary of AI Assistance

### 1. Project Planning
I asked ChatGPT to help me understand the assignment requirements and choose a project idea. We decided to create a Cultural Media Collection that documents films from different countries and cultures.

### 2. Python Setup
ChatGPT walked me through creating a virtual environment, activating it, installing the Rich library, and generating a `requirements.txt` file.

### 3. Python CLI
ChatGPT generated Python code for collecting film information, displaying records in a Rich table, confirming entries, and saving data to a JSON file.

I tested the program by entering *Spirited Away* and *Parasite*. Both records were saved successfully.

### 4. HTML Interface
ChatGPT generated an HTML version of the application with a form, a table, a confirmation popup, and a JSON download feature.

I tested the webpage by entering cultural media information and downloading the resulting JSON file.

### 5. Documentation
ChatGPT helped draft the README and this AI chat log.

## Example Prompts

- "Walk me through completing the CLI Data Curation assignment."
- "Give me the Python code for a Cultural Media Collection."
- "Help me create an HTML version of the application."
- "Help me document the project and prepare it for GitHub."

## Reflection
Using ChatGPT helped me understand how to set up a Python project and connect user input to structured data. I learned how to use the Rich library to display tables, save records using JSON, and create a basic HTML form that stores and exports data.

I also learned the difference between saving data directly to a file in Python and storing data in a browser using local storage.
