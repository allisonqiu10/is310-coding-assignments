# The Missing Grade

## Lost & Found in the Cultural Command Line

Your grade has mysteriously dropped, but you are not sure why. Navigate through different parts of a student's routine to investigate factors that could be affecting academic performance and find the missing factor.

### How to Play

Start with `START.txt`.

Use command-line tools to explore the maze and read the clues you find.

Helpful commands include:

- `ls` to see files and directories
- `cd` to move into a directory
- `cd ..` to move back one directory
- `cat filename.txt` to read a file
- `ls -a` to reveal hidden files

Your goal is to find `SOLUTION.txt`.

### Theme

This maze explores factors that can influence academic performance, including studying, gaming, social media, and sleep.
