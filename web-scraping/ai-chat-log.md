# AI Chat Log

## AI Tool Used

ChatGPT (OpenAI)

## How I Used AI

I used ChatGPT to help me understand how to build a web scraper using Python, requests, and BeautifulSoup.

ChatGPT walked me through installing the necessary libraries, testing requests to Minecraft Wiki, finding links on the Category:Items page, and extracting information from individual item pages.

I also used ChatGPT to help write Python code that saved the collected information into a CSV file and to organize the project README.

## Testing and Verification

I ran the Python script in VS Code and checked the terminal output after each step. I confirmed that the scraper could access Minecraft Wiki, collect five item descriptions, and save them to `wiki_data.csv`.

I also opened the CSV file to verify that the item names, descriptions, categories, and source URLs were present.

## Limitations

The AI-generated code required testing against the actual wiki structure. I verified the output rather than assuming the code would work correctly.

The final dataset is limited to five equipment items, and the category labels are not extracted individually from each article.
