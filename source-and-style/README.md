## Assignment 1: Inspecting the Cultural Web

### Website

For this assignment, I explored the Smithsonian Libraries Digital Library and looked at a digitized manuscript called *Manuscript of some works on Japanese tea ceremony*.

Website: https://library.si.edu/digital-library/book/manuscriptsomew00

### Technologies Used

I used Chrome DevTools to inspect the website. In the Elements tab, I found HTML elements such as `<div>`, `<section>`, and `<h1>`, which are used to organize the content on the page.

In the Styles panel, I found CSS from `style.css`. The CSS included properties for things like font size, margins, and padding. I also noticed media queries, which help the website adjust to different screen sizes.

In the Network tab, I found multiple JavaScript files being loaded, including `webtrends.js` and `analytics.js`. I also noticed that the website loads outside resources including Google Fonts, Google Analytics, Google Tag Manager, and Fundraise Up.
